# Forex Academy — Learn. Practice. Review.

A free, mobile-first educational website/PWA with 16 lessons from beginner to professional workflow, a glossary, knowledge checks, saved progress, and a risk-management reference.

## Files
- `index.html` — full website
- `manifest.webmanifest` — installable PWA metadata
- `sw.js` — offline caching after first visit
- `icon.svg` — app icon

## Publish free with GitHub Pages
1. Create/sign in to GitHub.
2. Create a public repository, e.g. `forex-academy`.
3. Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` to the repository root.
4. Go to Settings → Pages. Select Deploy from a branch, choose `main` and `/(root)`, then Save.
5. Open the HTTPS URL provided by GitHub Pages.
6. On Android Chrome, open the site menu (⋮) and select Install app or Add to Home screen.
7. Use it, and revisit the lessons as needed. Learning progress is stored in that browser on that device.

## Important
This is educational material, not financial advice or a promise of profitability. Trading is risky, especially when using leverage. It does not provide live prices, signals, broker integration, trade execution, or personalized investment recommendations. Content should be supplemented with broker contract specifications, local regulations, and independent practice. Browser data can be cleared, so progress may be lost; export it when needed.
